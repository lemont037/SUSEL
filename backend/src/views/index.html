Welcome to SUSEL

This is a static page for the SUSEL project.

Functioning Routes:

General Routes

  • GET / - Test route

Auth Routes

  • POST auth/register - Creates a new user

User Routes

  • GET /u/:uid/process - Get all active processes
  • GET /u/:uid/process/:pid - Get active process info by ID for user
  • GET /u/:uid/config - Get user information
  • POST /u/:uid/process/:pid/submit - Signs a User to Process

Admin Routes

  • GET /admin - Get all processes (admin)
  • GET /admin/process/:id - Get process by ID (admin)
  • POST /admin/new-process - Creates a new process

Check backend routes files for more details at Github.
